# v0.1.1 发布验证

本次在 v0.1.0 基础上验证直播文案持续追加：模型一轮返回多条候选时，每条分别写入数据库并通过 WebSocket 推到页面；下一轮能收到已记录文案，减少重复；空轮次不会清空之前的卡片。前端 233 项测试、TypeScript 检查和生产构建通过，相关后端测试 30 项通过。

发布包会用全新临时数据目录启动，检查版本 v0.1.1、空账号、空会议、语音运行库、停用上游更新、会议信息保存和正常关闭。此次验证不连接个人模型账号、不调用 GeWe，也不向微信群发送消息。

以下是 v0.1.0 的基础发布验证记录。

验证对象为 Apple Silicon Mac 的随听安装包与本仓库源码。

已完成的检查：前端 228 项测试、TypeScript 检查、生产构建；GeWe 19 项离线测试；说话人模型路径 3 项测试；中文转写过滤 9 项测试；发布规则 9 项测试；桌面启动器 29 项测试；13 项模型请求预算测试（其中 4 项验证实际请求参数，使用隔离加载的项目函数）。

已用全新临时数据目录启动成品 .app：空账号、空会议、版本 v0.1.0、本地语音运行库、上游更新安装被拒绝、拒绝后仍可保存会议信息、中文前端均通过。Docker Compose 默认配置与 GeWe 覆盖配置均通过语法解析。

模型连接的离线测试覆盖：手填模型不依赖模型列表、换地址不复用旧密钥、同一地址保留未重填的密钥、其他端点和模型不丢失、新建场次与保存风格保留所选模型。

GeWe 检查覆盖人工审核、只刷新群不发消息、重复点击、部分失败重试、结果不确定时阻止重发、账号切换、凭证路径与私有文件权限。测试使用虚拟账号和模拟接口，没有向真实群发送。

此前本机联调已通过 GeWe 获取群名，并向自己的文件传输助手发送测试文案；本次发布验证不重复外发。DeepSeek Flash 已完成四组短素材真实试写，其他供应商按官方协议提供接入，不宣称全部实测。

安装包独立数据目录检查与解压检查的最终结果在 GitHub Release 说明中记录。`scripts/smoke_macos.py --app /绝对路径/随听.app` 可重跑空账号、空会议、版本、语音运行库、上游更新禁用、会议信息保存与正常关闭检查。

语音运行库探测不等于模型首次下载或真实语音识别。首次 Whisper 权重下载、长时间多人直播的识别质量与性能，仍需要在实际电脑、音源和网络上开播前试跑。Docker 配置已检查，当前发布环境未运行完整 Docker 构建；Windows/Linux 没有发布已验收安装包。

当前包为临时签名，未做 Apple 公证。发布不包含维护者的密钥、录音、数据库、群列表或发送回执。
