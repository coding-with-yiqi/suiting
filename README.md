# 随听

把直播里正在讲的，写成群友想点进来听的消息。

**随听基于 [Backchannel](https://github.com/talberthoule/backchannel) 再封装**，面向中文直播和社群运营：听电脑声音、整理嘉宾发言、生成转播文案，再由人审核并选择几个微信群发送。

[下载 Mac 安装包](https://github.com/coding-with-yiqi/suiting/releases/latest) · [安装与构建](docs/安装与构建.md) · [连接 AI](docs/模型接入.md) · [连接微信](docs/GeWe.md)

## 怎么用

1. **连接 AI**：选择模型服务，填写自己的 API Key 和模型 ID。也可以连接自己运行的本地模型。
2. **新建一场**：先填写主题、直播入口、嘉宾称呼和听众。区分正在直播与回放，避免文案写错时间。
3. **去听**：默认听电脑上播放的声音。在浏览器的授权弹窗里选择可以分享声音的来源。腾讯会议、Zoom、OBS、视频号能否被采集，取决于系统和浏览器实际提供的音源；没有声音轨时程序会提示。
4. **看文案**：AI 根据当前转写挑一个具体亮点，留下适量悬念并附上本场入口。可以查看对应原话，修改正文。
5. **审核后发送**：选择群，确认完整正文和收件人，再点击发送。生成文案本身不会自动发微信。

## 微信怎么接，群号怎么找

随听使用 [GeWe 官方接口](https://doc.geweapi.com/)。先在 [GeWe 管理后台](https://manager.geweapi.com/) 连接自己的微信节点，再按 [GeWe 连接说明](docs/GeWe.md) 配置。

**不用自己查群号。** 把群保存到手机微信通讯录，在随听刷新群列表；程序通过 GeWe 取得群的内部 ID，再匹配成群名供你勾选。这里的群号不是腾讯会议号。重名群可结合内部 ID 核对，发送前务必确认目标。

一条文案可选择多个群，每个群分别显示发送结果。已成功或结果不确定的发送不会因为重复点击被自动重发；明确失败的目标可按界面重试。微信断线时仍可复制文案手动使用。

## 可以接哪些 AI

设置页提供 DeepSeek、Kimi、智谱 GLM、通义千问、豆包、OpenAI、Gemini、Claude，以及 Ollama 和自定义兼容服务的入口。模型 ID 可以手填，不要求服务商必须提供统一的模型列表接口。

Claude 使用官方实验性 OpenAI 兼容层，它会忽略部分结构化输出参数；不能视为原生完整适配。其他服务也要按自己所选型号验证。已实测的是 DeepSeek 的短素材试写，不代表全部服务商都逐一实测。

完整地址、官方链接、参数限制和验证范围见 [模型接入](docs/模型接入.md)。聊天网页会员、CLI 订阅和开发者 API 额度是不同入口；本项目不承诺免费调用。当前安装包提供 API 兼容服务入口，没有内置 Codex / Claude Code / Kimi Code 的登录代理。

## 对电脑的要求

当前提供 **Apple Silicon Mac（ARM64）** 安装包，包含 Python、数据库和运行库。Whisper Base 语音模型首次使用需下载，约 399 MB；建议在开播前准备好。轻量说话人模型随安装包提供，默认不安装较重的 Sortformer。

直播时，建议本机负责声音识别，云端模型负责写文案。和 OBS、会议软件同时试跑短场，检查音量、延迟和内存后再开正式直播。多人同时说话、背景音乐和音色相近会降低识别质量；程序能区分声音，嘉宾姓名仍需人确认。

Mac 包未完成 Apple 公证，首次打开方法、FFmpeg 的可选安装、Docker 及源码构建步骤见 [安装与构建](docs/安装与构建.md)。Windows/Linux 暂未提供随听成品安装包。

## 开发与数据

```bash
git clone https://github.com/coding-with-yiqi/suiting.git
cd suiting
```

上面 `cd suiting` 进入的就是项目目录；在这个目录执行安装文档中的命令。前端依赖由 `frontend/package-lock.json` 记录，后端依赖在 `backend/requirements.txt`，桌面构建依赖在 `desktop/requirements.txt`。

[文案与审核逻辑](docs/文案与审核.md) · [首次发布验证记录](docs/发布验证.md) · [来源与致谢](NOTICE.md)

应用用于本机，默认端口只绑定本机。录音、转写、凭证、群列表和发送记录保存在各使用者自己的数据目录。为兼容早期试用版，桌面内部程序名及默认数据目录仍保留 `Backchannel`；界面和分发名称为随听。不要把运行数据或填写后的配置提交到 GitHub。更新从随听自己的发布页下载，已停用上游自动更新。
